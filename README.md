# 慢记 · 个人生活记录 Demo

无需构建或安装依赖。用静态服务器打开本目录，例如 `python -m http.server 5173`，访问 http://localhost:5173 。

包含今天首页、万能记录、识别确认、状态与操作模式、待整理和七日回顾。草稿、记录与偏好保存在当前浏览器 localStorage。试用记录页示例，然后整理、确认保存即可完成流程。疲劳和震颤模式增大按钮并隐藏次要内容。Tab / Shift+Tab 导航，Enter 激活，记录页 Ctrl/Cmd+Enter 识别。

识别为本地规则演示，并非远程 AI；趋势在没有真实记录时明确展示示例数据。语音使用浏览器 SpeechRecognition，支持程度与麦克风授权取决于浏览器，可能由浏览器语音服务处理，建议通过 localhost 或 HTTPS 使用。无后端或云同步。

## 交互优化

- 首页支持“有点累 / 心情不错 / 感觉平静”一键保存；不打断已有草稿。
- 震颤模式扩大间距与按钮，过滤 900ms 内重复激活；正常模式过滤 350ms 内重复激活。
- “最近操作”持久化保存新增、编辑、删除及待整理操作。撤销按记录恢复，不回滚整个应用；遇到后续修改冲突时阻止覆盖。撤销已提交文字后，原文恢复到待整理。
- 首次保存真实记录后隐藏示例，示例与个人统计分开；可手动查看示例。
- 时间线提供编辑入口，修改自动暂存；支持金额、时长、文字、日期和时间修改，删除前确认，删除后可撤销。
- 回归检查：`node verify.cjs`。覆盖独立撤销、冲突保护、编辑、删除恢复、草稿保护及历史持久化。
